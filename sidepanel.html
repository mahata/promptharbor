Connecting sends this PAT, and then your prompts and any pages you include, to GitHub through the companion and the GitHub Copilot CLI on this Mac.

Once GitHub accepts the PAT, the companion always saves it in your macOS login keychain and connects with it every time you open this panel, until you sign out. Other programs running as your macOS user can read it there without macOS asking you, so use a PAT that expires soon and has no other permissions.
